# Raw Engineering Documents Directory

This directory stores raw, unmodified engineering documents and CAD files ingested into the system.

### Supported File Types:
- **Specifications & Manuals**: `.pdf`, `.docx`, `.txt`, `.md`
- **Spreadsheets & BOMs**: `.xlsx`, `.csv`
- **CAD Models & Drawings**:
  - 3D Neutral Formats: `.step`, `.stp`, `.iges`, `.igs`, `.stl`, `.obj`
  - 2D Drawings: `.dxf`, `.dwg`

> **Note**: Files placed here are tracked locally for ingestion and testing but are excluded from git version control via `.gitignore`.
