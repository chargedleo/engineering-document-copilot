# Processed Engineering Knowledge Artifacts

This directory stores intermediate artifacts, extracted text, and normalized geometric metadata generated by the ingestion pipeline.

### Artifacts stored here:
- **Extracted Text & Chunks**: JSON/markdown extracts from PDFs, datasheets, and manuals.
- **CAD Metadata Representations**: Normalized JSON trees depicting part hierarchies, materials, tolerances, and dimensions extracted from CAD files.
- **Visual Previews**: Cached 2D raster thumbnails or GLTF/GLB web-friendly 3D geometry derived from CAD source files.

> **Note**: These files are ephemeral / generated and excluded from git version control.
